# Neloy Enterprise

**Modernizing Spaces with Quality Glass & Custom Interiors**

Neloy Enterprise is a custom manufacturing business for home, shop and office decoration.

## What we build

- Glass & aluminium windows
- Glass & aluminium doors
- Glass showcases
- Melamine board bookshelves
- Custom home décor
- Glass partitions
- Custom mirrors
- Shop display and storage units

## Website goal

A customer should be able to choose a product, enter dimensions and options, see an estimated live price, review the design summary and request a quotation through WhatsApp.

## Development

The current prototype lives in `index.html`. The project will gradually move toward a modular structure with separate product, pricing, material and configurator modules.

See [PROJECT-STRUCTURE.md](PROJECT-STRUCTURE.md) for the full architecture.
